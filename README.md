# Honey Chouhan — Business Analyst Portfolio

A responsive, dependency-free portfolio site. Open `index.html` in a modern browser. The hero uses the 124 adjacent JPEG files named `ezgif-frame-001.jpg` through `ezgif-frame-124.jpg` and advances as you scroll.

Before publishing, update the contact email in `index.html` (`hello@example.com`) and replace any general portfolio copy with your preferred details.
